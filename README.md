# ELA Quest — Complete Rebuild

A self-contained classroom reading game, designed using the ELA Quest fantasy dashboard reference.

## Publish on GitHub Pages
1. In the `Streamsintowealth/ELAQuest` repository, open the `index.html` file.
2. Click the pencil icon (Edit) or upload the new `index.html` to replace the old one.
3. Commit the change to the `main` branch.
4. In **Settings → Pages**, confirm that publishing uses `main` and `/ (root)`.
5. Open `https://streamsintowealth.github.io/ELAQuest/`, then hard-refresh.

**Keep a backup first**: download the old repository file or use GitHub commit history.

## What's inside
- Ten clickable avatar portraits derived from the supplied design mockup
- Vocabulary, informational text, and literature paths; 16 selectable skills
- Six different mission engines: Adventure, Battle, Team, Scavenger, Time, Puzzle
- Action unlocked by correct answers; actual attacks, treasure, map interaction, repairs, race progress, and puzzle tiles
- Original reading texts: five passages preserved from the earlier ELA Quest source plus thirteen new passages
- Time sessions 10 / 15 / 20 minutes; reading-range choices; hints and feedback; score, streak, mission progress, review summary
- Optional synthesized background music (OFF at launch), sound-effect toggle and separate volume settings
- Confetti/animations, reduced-motion option, browser read-aloud, larger text, keyboard answers, accessible buttons
- TRACES writing help. No third-party scripts, login, database, advertisements, or external image dependencies.

### Reading level note
Difficulty labels are approximate instructional ranges. No passages have been formally assessed for Lexile level.

### Text source note
All passages inside this game are original sample passages. They are **not copied from NYSED released exams**. The preserved starter passages were labelled original in the earlier source.

### Files
`index.html` is the **only required website file**. It contains the game, images, styles, and sounds; GitHub Pages can host it directly.
